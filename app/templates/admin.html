Pipeline (command line)

python scripts/make_aois.py          # rebuild wetland boundaries from OpenStreetMap
python -m src.download --all         # build Sentinel-2 cubes (needs internet, resumable)
python -m src.analysis --all         # train models, detect, evaluate, write maps/metrics
python -m app.app                    # serve this app at http://127.0.0.1:5000
python -m src.load_postgis           # (optional) load results into PostGIS when DB is up
python -m pytest tests/ -q           # run the test suite

To monitor a new wetland: add its boundary to data/aoi/, add one entry to WETLANDS in src/config.py (boundary file, window, normal-period end date), then run the three pipeline commands with --site <name>.

Field verification (next step)

data/field/field_verification_template.csv lists the columns to complete on site visits: alert ID, GPS, photo, observed land cover, and whether the detected change is confirmed. Confirmed points become gold-standard reference data and replace the silver-standard evaluation.
