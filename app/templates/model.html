Model

The network does not classify change directly. It learns what NDVI should be, for this wetland, in a given season. Change is the leftover, and it counts only when that leftover stays.

Persistence rule

On each post-opening date, a pixel is anomalous when observed NDVI exceeds the expected value by {{ "%.3f"|format(metrics.model.threshold) }}. The pixel is a persistent change when that happens for {{ metrics.model.min_consecutive }} successive kept observations. The threshold and the run length were chosen on tuning blocks, then frozen for the held-out blocks.

Baseline

The baseline subtracts NDVI on {{ metrics.baseline.pre_date }} from NDVI on {{ metrics.baseline.post_date }}. A pixel is flagged when the later date is higher by {{ "%.2f"|format(metrics.baseline.threshold) }}. There is no seasonal model and no check that the increase lasts.
